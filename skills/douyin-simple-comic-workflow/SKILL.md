# 抖音静态漫画：FAST / STRICT

默认用于静态抖音漫画、故事插画组图。不制作视频，不自动发布。新任务使用新的独立项目目录，保留历史成品。

## 画风与人物选择

![三套已确认人物画风的头像与半身预览](assets/style-previews/character-style-preview.png)

从左到右为都市韩漫、Q版轻喜剧、清雅古风叙事。图片只展示画法，具体人物仍依据本故事重新设计。

新项目支持三套已选画风：**都市韩漫、Q版轻喜剧、清雅古风叙事**。生成前遵照用户本次选择或明确要求继承的项目风格；没有选择依据时展示三项与预览供选择，用户授权助手选择时可推荐并记录理由。读取 [画风预设与逐页表达](references/style-presets.md) 和所选规格，不默认加载整个外部画风库。保留原有自定义画风与真实参考图能力。

先确定画风，再按本故事建立人物卡，联合规划每页的表演、镜头、分镜与文字。预设提供倾向，每页仍按语境、动作和情绪选择原SB及文字形式；不把一种画风绑定一种分镜或统一字幕。样图人物不自动成为新故事主角。恢复冻结任务沿用该任务快照，不重新选风格或修改历史图片。

## 先选择模式，再读取对应资料

- **FAST（新日常任务默认）**：一次规划时按真实语境、情绪和动作选择原有 SB，联合设计画面与文字，实际字体试排后冻结；整页生成，再依据实际人物与画格完成本地文字。读取 [FAST 工作流](references/fast-workflow.md) 和 [FAST 配置](config/fast.json)，只加载选中的 SB。FAST 复用原有叙事选择与文字绘制能力，保留构图参考性质，不执行 STRICT 逐格生产或精确验收。
- **STRICT**：用户要求精确画格、严格气泡位置、精确分镜结构、完整 SB 验收或明确指定 STRICT 时，读取 [原有严格流程](references/strict-workflow.md) 和 [严格生产操作](references/production-workflow.md)。保留全部 68 套 SB、逐格素材、确定性组版及原有验收。不把 FAST 成品标为 STRICT 通过。
- **恢复已有任务**：优先检查项目里的 `fast/plan.json` / `fast/state.json` 或旧版 `production-state.json`。按该项目原来的模式恢复；不要把旧 STRICT 项目自动迁移到 FAST。精确要求无法在 FAST 中满足时保留当前成果，在新的 STRICT 项目继续。

## 两种模式共用的实际生图约束

生产仅使用 **Codex 内置 GPT `image_gen`**。本地脚本只负责规划保存、状态、文件复制校验和文字后期；它们不生成画面。直接调用内置工具，传入实际参考图；首次使用本地参考图前先查看它。

不得切换到 `scripts/image_gen.py`、外部图片 API、`OPENAI_API_KEY`、CLI 生图或第三方模型。内置工具不可用时停止，保存状态并报告。不要用占位图、Pillow 模拟画面或提示词冒充 GPT 图片。离线开发测试必须显式标为 simulation，不能作为生产图片交付。

每次生图都要保留真实工具返回的图片：把实际文件复制到本次项目目录，重新读取并验证成功后再记录成功。工具只显示图片但没有可取得的文件时，记录保存阻塞，保留该次调用；先恢复实际输出，不因保存失败再次付费生图。

## FAST 的关键约定

FAST 默认使用精简生图提示词：只发送本页必要的画风、人物、分镜动作、构图与文字留白，完整分析、字幕和审核数据留在本地。冻结前检查实际拼接后的请求，去掉重复规范和后页内容；不靠硬截断或删除关键剧情缩短文本。具体编写与拼接规则见 [FAST 工作流](references/fast-workflow.md)。精简是请求质量改进，不把网络失败直接归因于提示词长度。

优先缩短准备与减少重复调用：在原有一次规划里联合确定图文位置，公共画风和角色卡只写一次，每页用 `character_ids` 列出实际出场人物；脚本只携带这些人物卡及其专属参考。不要为同一篇原稿另开重复分析轮次或默认增加试风格图、测试图、多个候选；首张就是正式第1页。共用身份参考可放在首张的 `reference_paths`，后续复用审核过的首张；本页需要的新人物参考或用户指定的持续参考仍保留。具体轻量检查见 FAST 工作流，不新增模板数量配额。

读故事后在同一次规划中写好分析、人物卡、画风、分镜、字幕与最终提示词并保存。分镜确认后冻结，恢复只读已有状态和当前页请求；修一页不重新分析整篇故事。已有明确创作授权且无需额外选择时可直接采用规划并冻结，不新增确认轮次。

每页写清叙事功能、最少充分画格的理由、每格的主动作或情绪和文字归属。从原有 68 套 SB 选型；叙事匹配优先，相近候选才考虑前后变化。有叙事理由可以重复，不设固定轮换或最低版式配额。复杂 SB 的近似改编须明确记录；不能用通用网格替代原模板后宣称执行通过。

一页默认一个最终候选；首张有文字的新任务先完成正式第 1 页的本地排字，实际查看成品并记录分镜表达、图文关系及阅读顺序，队列通过后再继续剩余页。首张无文字时不增加排字审核；旧冻结计划沿用原规则。每页最多 2 次生图尝试，只重试失败页；有效成功图片必须跳过。复用人物/画风参考；没有现成参考时可复用第 1 页，不默认增加参考图生图任务。

新任务保存图片后先做当前页轻量视觉检查，再开放后续任务。文件成功只表示可读且已保存，人物、关键情节和分镜执行需另行记录。参考图继承人物、服装与画风，本页 SB 决定构图。画面确实失败时先记录，再明确登记并使用该页剩余的一次重试；字幕问题只在本地处理。

生成画面无中文字、字幕或气泡；本地复用原有旁白、对白、心声、喊话和说明绘制能力。语义保持原文，气泡不能把旁白改成台词。生图前用实际字体和目标尺寸检查容量；生图后由看过当前图片的调用者提供人物、画格和避让区域，不能把计划坐标冒充真实测量。独立修订可局部重排，不重生底图；最终选定的字幕版本及成品路径需持久保存供恢复与交付使用。保留人工验收状态，不执行出版级整库验收。

不能取得内置工具真实 Token、额度或费用时，这些值记为 `null`。区分已派发尝试、已记录工具结果和未知中断；只报告可证实的调用次数和任务情况，不推算费用或宣称固定节省比例。
