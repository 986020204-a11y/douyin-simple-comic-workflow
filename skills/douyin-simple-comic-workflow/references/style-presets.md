新项目可选「都市韩漫」「Q版轻喜剧」「清雅古风叙事」，也支持原有自定义风格和用户参考图。风格不是固定人物、固定分镜或全局字幕模板。

## 选择与继承

已有冻结任务先恢复该任务，不读取最新风格库改写旧规划。新任务优先遵照用户本次明确选择；用户要求沿用项目风格时继承已经确认的风格；用户提供自定义描述或参考图时保留原能力。用户授权由助手选择时，可结合本故事推荐并记录理由。没有明确选择或继承依据时，生成前展示三项名称与预览，给用户选择机会，同时可先分析故事；不擅自把某题材永久绑定一种风格。

| 选项 | 稳定ID | 视觉重点 | 预览 |
|---|---|---|---|
| 都市韩漫 | urban-webtoon | 人物关系、成年比例、细微表情、精致都市画面 | [人物画像左栏](../assets/style-previews/character-style-preview.png) |
| Q版轻喜剧 | chibi-comedy | 约3至3.5头身、表情与姿态的喜剧反差 | [人物画像中栏](../assets/style-previews/character-style-preview.png) |
| 清雅古风叙事 | ancient-fine-line | 细线人物、服饰仪态、含蓄情绪与古风连续叙事 | [人物画像右栏](../assets/style-previews/character-style-preview.png) |

预览只用于选择画风，三栏分别对应左、中、右三项；不要把整张多画风预览图自动传给生图模型。样图人物是示例，不是每个新故事的固定主角；从当前故事重新制作人物卡。已有同IP人物只有在用户要求复用时才继承。此前的整页对比图与古风场景样张仍保留作选型历史。

都市韩漫与古风的库中定义分别参考 yang0 的 [handraw-style](https://github.com/yang0/handraw-style) FG-021／旧327、FE-034／旧203。Q版为此前确认的通用设计，不冒称库中1.5头身条目。本人物画像预览依据此前用户选择的三套样张实际生成，用于展示已选画法，不代表新人物已经定稿或长篇一致性已自动验证。

## 在规划中使用

查看菜单或只读取所选规格：

```powershell
python <SKILL>/scripts/fast_style.py list
python <SKILL>/scripts/fast_style.py show --preset 都市韩漫
```

新FAST草案可用以下字段，不必手工重复整份画风描述：

```yaml
style:
  preset_id: urban-webtoon  # 也接受中文名或已列出的别名
  prompt: "本故事使用灰绿与米白，人物服装以人物卡为准。"  # 可选项目补充
  reference_paths: []  # 用户选定的真实人物/风格参考，预览不会自动加入
pages:
  - page_id: P01
    # 原有叙事、SB、panels、prompt、captions 等字段照常填写
    style_application:
      performance: "她压住笑意，他仍然冷淡；以嘴角与视线表现反差。"
      camera: "先看手机，再看她的反应，最后交代两人距离。"
      layout: "按三个必要叙事节点选择合适原SB，最后一格留出反应停顿。"
      lettering: "到账信息作为说明，原文对白绑定说话者，心声独立；逐格避开脸和手。"
```

每页四项 `style_application` 是结合本页剧情写的实际决定，不得整组机械复制同一段。它们分别把画风落实到表演、镜头、分镜表达和文字设计；同一故事采用另一画风时允许重新规划这些决定，不要求必然换SB。人物卡、原文语义和本页叙事是依据。

人物设计应覆盖本故事需要的脸型、发型、衣服剪影、年龄与稳定特征。Q版改变绘画比例，不改变原文年龄和人物关系；古风先确定朝代或架空设定、身份和场合，不能只给现代人物换衣服，也不把所有古风固定成同朝代。

从原有SB按叙事选型，预设只给倾向，不绑定模板、格数、轮换或配额。人物一致性优先，分镜表达其次，背景丰富度最后。对白、旁白、心声、说明仍遵循原文类型；字形可保持整组统一，容器与位置按画格、情绪、说话者和实际画面设计，避免退回统一覆盖。

脚本把所选预设与版本完整快照到 `fast/planning/style.json`，每页表演、镜头、分镜决定进入生图提示词；文字决定进入该页字幕规划元数据，实际容器、字号和试排仍由原字幕流程执行。只写预设ID却缺少逐页应用决定的新计划会在生成前被拒绝。脚本不自动理解语境，也不把元数据当成真实视觉验收。

预设快照为脚本派生字段，新草案不要手工填 `preset_snapshot`、`preset_version`、`preset_name` 或 `planning_guidance`。无 `preset_id` 的旧版和自定义 `style.prompt` 草案继续使用原行为。

## FAST与STRICT边界

保持一次整组规划、字体试排、冻结、一页一个候选、最多两次尝试、首图参考复用、成功跳过与复制恢复。选预设不自动新增参考图生图，不改变生成调用上限。冻结后只改字幕仍在本地修订，不改冻结画风、不触发重生；整组换风格在新项目重新规划。

STRICT也可读取这些预设作为美术规划参考，但继续使用原有逐格生产、模板几何、严格文字与验收流程；此次没有修改STRICT执行器或任何SB模板。

用户可直接说：

- “使用新版FAST，画风选都市韩漫，把下面的故事做成3:4漫画。”
- “这篇用Q版轻喜剧，突出人物的表情反差，按情节安排分镜和文字。”
- “用清雅古风叙事，架空古代背景，先统一人物服饰与发式再规划。”
