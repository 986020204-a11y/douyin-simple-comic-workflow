# FAST 精简提示词验证：1.2.3-rc.1

本版同步通用技能 `1.2.3-fast-compact-prompts`，新 FAST 项目默认用精简的本页请求生成完整漫画页。完整故事分析、人物卡、字幕正文、字体和审核记录继续保存在项目本地。

## 验证范围

- 拼接保留当前页人物辨识特征、作者的画风与视觉要求、所选原 SB 的叙事机制、每格动作和镜头、文字空间及归属；不把整份制作记录展开成提示词。
- 原文、分析、完整人物卡和字幕仍保存；未出场人物、私有备注和字幕正文不进入生图请求。
- 不按字符数量硬截断作者要求；规划者在冻结前清理重复说明与跨页内容。
- 实际有参考图片时，由队列添加身份、服装与画风的参考规则；动态复用第1页仍正常，当前页分镜控制构图。
- 首张有文字的新计划必须完成底图审核、本地排字及选定成品检查，后页才开放；错误或过期成品审核不会放行。
- 恢复已有冻结项目不调用新拼接器，不重写提示词、角色或字幕输入，也不重置尝试次数。

## 可重复的离线检查

```sh
python -B -m unittest discover -s skills/douyin-simple-comic-workflow/scripts/tests -p 'test_fast*.py' -q
```

本版 118 项 FAST 离线测试通过。测试只使用独立临时目录和明确标记的模拟素材，不调用外部服务或图像模型。技能格式、插件 JSON 版本与默认入口一致性另行检查。

## 结果边界

本次没有新增真实生图调用。离线通过验证的是信息保留、提示词拼接、状态和审核门槛；不能据此宣称漫画审美质量、实际生图成功率、速度或费用得到保证。精简提示词是工作流质量改进，不能单凭网络错误认定失败由提示词长度导致。

STRICT 和分镜库未作修改，本轮不重新执行整库渲染或将历史视觉验收套用于新版 FAST。
