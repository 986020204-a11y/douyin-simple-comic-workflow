## 离线验证

在本次同步的技能包中执行 FAST 测试，原有93项加新增9项，共102项。新增覆盖：三项菜单和别名解析、自定义风格兼容、所选预设快照、逐页表演／镜头／分镜决定进入提示词、文字决定进入字幕计划、缺少逐页应用时生成前拒绝、冻结恢复不重读画风库、成功图跳过、人物及第一页参考复用、字幕重排不改变底图或派发次数、从技能目录外调用菜单。

测试素材明确标记为 SIMULATION 并位于独立临时目录，测试不调用真实生图工具。离线通过不代表真实画风还原、跨页人物一致性或成品视觉验收。

技能入口通过 skill-creator 的格式校验；菜单三项均指向包内人物画像预览，并注明左／中／右对应关系。技能和仓库README使用相对图片链接，安装路径变化不依赖私人磁盘路径。
